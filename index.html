Teams

Each section starts with a line beginning with # (the title). A line beginning with ## sets that section's description. Question lines may include a leading number; question and answer split on a colon (:) or a question mark (?). A line beginning with >> is a sub-part of the question above it — each sub-part is awarded to a team independently with its own points. 

# Section 1: Section name
## Description
1. Question?: Answer
2. Question?: Answer

# Section 2: Section name
1. Question with sub-parts:
>> Part 1?: Answer
>> Part 2?: Answer
2. Question?: Answer
